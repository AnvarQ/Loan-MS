## ⚙️ ПОДГОТОВКА (Делается 1 раз)

### Шаг 1: Установи VS Code
1. Скачай: https://code.visualstudio.com/
2. Установи с настройками по умолчанию
3. Запусти VS Code

### Шаг 2: Установи Python
1. Скачай: https://www.python.org/downloads/
2. ⚠️ **ВАЖНО:** При установке поставь галочку **"Add Python to PATH"**
3. Перезагрузи компьютер после установки

### Шаг 3: Проверь установку
Открой VS Code → Terminal → New Terminal
Напиши:
```bash
python --version
```
Должно показать: `Python 3.8` или выше ✅

---

## 📥 СКАЧИВАНИЕ ПРОЕКТА (Делается 1 раз)

### Вариант A: Через Git в VS Code

#### 1. Открой командную палитру:
- Нажми `Ctrl+Shift+P` (Windows/Linux)
- Или `Cmd+Shift+P` (Mac)

#### 2. Клонируй репозиторий:
- Набери: `Git: Clone`
- Вставь: `https://github.com/AnvarQ/Loan-MS.git`
- Выбери папку куда сохранить
- Нажми "Open" когда появится уведомление

#### 3. Переключись на рабочую ветку:
Открой терминал в VS Code (`Ctrl+\``) и напиши:
```bash
git checkout claude/production-ready-S98f3
```

### Вариант B: Скачать ZIP

#### 1. Скачай проект:
- Иди на: https://github.com/AnvarQ/Loan-MS
- Нажми зеленую кнопку **"Code"**
- Выбери **"Download ZIP"**

#### 2. Распакуй:
- Распакуй ZIP в удобное место
- Например: `C:\Projects\Loan-MS`

#### 3. Открой в VS Code:
- VS Code → **File** → **Open Folder**
- Выбери папку `Loan-MS`

## 🔧 НАСТРОЙКА ПРОЕКТА (Делается 1 раз)

### Шаг 1: Открой терминал в VS Code
Нажми: `Ctrl+\`` (обратная кавычка)
Или: **Terminal** → **New Terminal**

### Шаг 2: Перейди в папку backend
```bash
cd backend
```

### Шаг 3: Установи зависимости
```bash
pip install -r requirements_dev.txt
```

⏳ Подожди 1-2 минуты пока установятся библиотеки...

**Если ошибка "pip not found":**
```bash
python -m pip install -r requirements_dev.txt
```

**Если на Mac/Linux:**
```bash
pip3 install -r requirements_dev.txt
```

### Шаг 4: Создай базу данных

Должно появиться:


```bash
python create_superuser.py
```

Должно появиться:

- Нажми **"Funds"**
- **Объясни:** Управление финансовыми фондами для кредитования

- **Объясни:** Система логирует все изменения (audit trail)

✅ **ПОКАЖИ ПРЕПОДАВАТЕЛЮ:** Все модули работают!

### 🟢 ЧАСТЬ 4: ПОКАЖИ КОД

#### 1. Структура проекта
В VS Code (левая панель Explorer) покажи:

```
backend/
├── manage.py              ← Главный файл Django
├── backend/
│   ├── settings.py        ← Настройки проекта
│   └── urls.py            ← URL маршруты
├── user/                  ← Модуль пользователей
│   ├── models.py          ← Модель User
│   ├── views.py           ← API endpoints
│   └── tests.py           ← Тесты
├── loan/                  ← Модуль кредитов
│   ├── models.py          ← Модель Loan
│   └── views.py           ← Логика кредитов
└── fund/                  ← Модуль фондов
    └── models.py          ← Модель Fund
```

#### 2. Открой важные файлы:

**`user/models.py`** - покажи модель User:
```python
class User(AbstractBaseUser):
    email = models.EmailField(unique=True)
    is_customer = models.BooleanField(default=False)
    is_agent = models.BooleanField(default=False)
    is_admin = models.BooleanField(default=False)
```

**`loan/models.py`** - покажи модель Loan:
```python
class Loan(models.Model):
    STATUS_CHOICES = (
        ('NEW', 'New'),
        ('APPROVED', 'Approved'),
        ('REJECTED', 'Rejected'),
    )
```

✅ **ПОКАЖИ ПРЕПОДАВАТЕЛЮ:** Чистый, организованный код!

## 🎯 ЧТО ГОВОРИТЬ ПРЕПОДАВАТЕЛЮ

### Про технологии:
> "Проект построен на Django REST Framework с JWT аутентификацией.
> База данных - SQLite для разработки, PostgreSQL для production.
> Архитектура - трехуровневая ролевая модель доступа."

### Про функционал:
> "Система управления кредитами с тремя типами пользователей:
> - Клиенты могут подавать заявки на кредиты
> - Агенты обрабатывают и одобряют заявки
> - Администраторы управляют всей системой"

### Про тестирование:
> "Написано 60 unit тестов, все проходят успешно.
> API полностью протестировано, все endpoints работают."

### Про безопасность:
> "Используется JWT токены для аутентификации,
> PBKDF2 + SHA256 для хеширования паролей,
> Permission-based контроль доступа,
> CORS настроен для безопасности."
