## ⚡ БЫСТРАЯ УСТАНОВКА

### 1. Скачать проект
```bash
git clone https://github.com/AnvarQ/Loan-MS.git
cd Loan-MS
```

### 2. Переключиться на рабочую ветку
```bash
git checkout claude/production-ready-S98f3
```

### 3. Установить зависимости
```bash
cd backend
pip install -r requirements_dev.txt
```

### 4. Создать базу данных
```bash
python manage.py migrate
python create_superuser.py
```

### 5. ЗАПУСТИТЬ! 🚀
```bash
python manage.py runserver
```

## 🔧 ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ

### "python: command not found"
**Решение:** Используй `python3`:
```bash
python3 manage.py runserver
```

### "Port 8000 already in use"
**Решение:** Используй другой порт:
```bash
python manage.py runserver 8080
# Открыть: http://127.0.0.1:8080/admin/
```

### "No module named django"
**Решение:** Установи зависимости:
```bash
pip install -r requirements_dev.txt
```
