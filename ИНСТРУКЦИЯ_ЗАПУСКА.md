## 📋 ЧТО НУЖНО УСТАНОВИТЬ

### 1. Python 3.8 или выше
**Windows:**
- Скачать с официального сайта: https://www.python.org/downloads/
- При установке ОБЯЗАТЕЛЬНО поставить галочку "Add Python to PATH"
- Проверить установку: открыть CMD и написать `python --version`

**macOS:**
```bash
brew install python3
```

**Linux (Ubuntu/Debian):**
```bash
sudo apt update
sudo apt install python3 python3-pip python3-venv
```

### 2. Git
**Windows:**
- Скачать с: https://git-scm.com/download/win
- Установить с настройками по умолчанию

**macOS:**
```bash
brew install git
```

**Linux:**
```bash
sudo apt install git
```

## 📦 ШАГИ ДЛЯ ЗАПУСКА ПРОЕКТА

### ШАГ 1: Клонировать проект с GitHub

Откройте терминал (CMD на Windows) и выполните:

```bash
git clone https://github.com/AnvarQ/Loan-MS.git
cd Loan-MS
```

**Если нужна конкретная ветка (production-ready):**
```bash
git checkout claude/production-ready-S98f3
```

---

### ШАГ 2: Установить зависимости

```bash
# Перейти в директорию backend
cd backend

# Установить все Python библиотеки
pip install -r requirements_dev.txt
```

**Если возникнет ошибка с pip:**
```bash
# Попробуйте с pip3
pip3 install -r requirements_dev.txt

# Или с python -m pip
python -m pip install -r requirements_dev.txt
```

---

### ШАГ 3: Создать базу данных

```bash
# Применить миграции (создать таблицы)
python manage.py migrate
```

**Ожидаемый результат:**
```
Running migrations:
  Applying contenttypes.0001_initial... OK
  Applying user.0001_initial... OK
  Applying admin.0001_initial... OK
  ...
```

---

### ШАГ 4: Создать администратора

**Вариант A (автоматический):**
```bash
python create_superuser.py
```

**Вариант B (ручной):**
```bash
python manage.py createsuperuser
# Email: admin@loanms.com
# Password: admin123
```

---

### ШАГ 5: ЗАПУСТИТЬ СЕРВЕР! 🎉

```bash
python manage.py runserver
```

**Вы должны увидеть:**
```
Starting development server at http://127.0.0.1:8000/
Quit the server with CTRL-BREAK.
```

## 🔧 ВОЗМОЖНЫЕ ПРОБЛЕМЫ И РЕШЕНИЯ

### Проблема: "python: command not found"
**Решение:**
```bash
# Попробуйте python3 вместо python
python3 manage.py runserver
```

### Проблема: "No module named django"
**Решение:**
```bash
# Установите зависимости еще раз
pip install -r requirements_dev.txt
```

### Проблема: "Port 8000 already in use"
**Решение:**
```bash
# Используйте другой порт
python manage.py runserver 8080
```

### Проблема: "Permission denied"
**Решение (Linux/macOS):**
```bash
chmod +x manage.py
python manage.py runserver
```
