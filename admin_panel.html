🌐 Доступ к приложению

⚠️ Важно: Вы работаете в Claude Code в браузере. Чтобы открыть админ-панель в браузере:
  1. В Claude Code найдите вкладку "PORTS" в нижней панели
  2. Нажмите "Forward a Port"
  3. Введите порт: 8000
  4. Откроется ссылка в браузере
  5. Добавьте /admin/ к URL

📡 API Endpoints

Base URL: http://localhost:8000/api

User Management:

POST /api/user/signup/ - Регистрация
POST /api/user/login/ - Вход
GET /api/user/profile/ - Профиль
POST /api/user/create-admin/ - Создать админа
GET /api/user/list-agent/ - Список клиентов
GET /api/user/list-approvals/ - Все пользователи

Loan Management:

POST /api/loan/customer-loan/ - Создать кредит
PUT /api/loan/approve-reject-loan/<id>/ - Одобрить/отклонить
GET /api/loan/list-loans-admin-agent/ - Все кредиты
GET /api/loan/list-loans-customer/ - Мои кредиты

🛠️ Технологический стек

Backend Django 3.2.5
API Django REST Framework
Auth JWT Tokens (2h)
Database SQLite / PostgreSQL
Security PBKDF2 + SHA256
DevOps Docker Compose

🎯 Альтернативные способы доступа

1. Через командную строку:

# Войти в систему
curl -X POST http://localhost:8000/api/user/login/ \\
  -H "Content-Type: application/json" \\
  -d '{"email": "admin@loanms.com", "password": "admin123"}'

# Получить профиль (замените TOKEN на полученный токен)
curl http://localhost:8000/api/user/profile/ \\
  -H "Authorization: Bearer TOKEN"

2. Скачать проект на свой компьютер:

Скачайте архив OST-Loan-Management-System.tar.gz и запустите локально:

cd OST-Loan-Management-System
./setup_and_run.sh
./run_server.sh
